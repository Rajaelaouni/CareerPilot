🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════════

  1. Configure:
     cd interview_service
     cp .env.example .env
     # Edit .env: OPENAI_API_KEY=sk-your-key

  2. Install:
     pip install -r requirements.txt
     cd ../frontend && npm install

  3. Run (3 terminals):
     # Terminal 1:
     cd interview_service && python main.py
     
     # Terminal 2:
     python manage.py runserver 8000
     
     # Terminal 3:
     cd frontend && npm run dev

  4. Access:
     http://localhost:5174 🎉
